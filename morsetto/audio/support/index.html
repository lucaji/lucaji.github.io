MorsettoAudio shapes stereo audio inside your music host. These notes cover the AUv3 plug-in workflow on iPhone, iPad and Mac.

Open the offline user manual

Open the MorsettoAudio app and choose User Manual for the complete control reference. The guide is bundled with the app and works offline. On Mac it opens in a separate resizable window; Help → MorsettoAudio Help or Command-? opens the same guide. On iPhone and iPad it opens in a sheet; choose Done to close it.

Contact

For help, email Luca Cipressi · Milletgrain at lucaji.milletgrain@gmail.com .

Please include:

  • your device model and operating-system version;
  • the MorsettoAudio version and build number;
  • the host name and version, and where the plug-in is inserted;
  • the steps that reproduce the problem, including whether host playback is running;
  • the relevant pattern and mapping settings, or a screenshot when useful.

For clicks or timing problems, include the host’s sample rate and buffer size if available. Remove personal information from screenshots and only share audio you have permission to send. Support never needs your App Store password.

Set up the audio route

  1. Install MorsettoAudio on your device.
  2. In a compatible host, insert its AUv3 audio effect on a stereo audio or instrument track.
  3. Confirm that the track produces sound with the effect bypassed, then enable the effect.
  4. Start with the free MORSE pattern, keep Morse Envelope → Amplitude connected, and start the host’s transport. With Pro, you can also apply custom text.

The host supplies the audio and musical timing. Use its recording or export commands to capture the result. The accompanying app provides version information, the offline manual and Pro purchases/restoration; it can stay closed during music-making.

Free, Pro and restoring a purchase

Free · MORSE gives you unlimited use of the canonical MORSE phrase, its original spacing and full loop from zero. Subdivision, triplets, all five mapping slots and destinations, five modulation sources including the main-input Audio Envelope follower, shaping, automation, grid/zoom navigation and host saving remain available. Sidechain requires Pro.

Pro unlocks text, character spacing, leading silence, loop editing and Sidechain through a permanent one-time purchase. MorsettoAudio Pro and MorsettoMidi Pro are separate purchases.

  1. Open the MorsettoAudio app and choose Get Pro or Manage Pro. In the purchase sheet, buy Pro or choose Restore Purchases using the App Store account that purchased it. Restoration may ask you to sign in.
  2. Check the app’s purchase and sharing messages. If it reports a sharing problem, use Retry.
  3. Return to the plug-in and choose its Free / Pro status button to refresh shared access, or close and reopen its editor.

The status button reads the access shared by the app; it does not purchase or restore through the App Store. If a purchase awaits approval, Free stays available. An unavailable price does not prevent restoring an existing purchase. Include the exact app and plug-in messages when requesting help.

While Free, Unlock all features from the app requests the containing app. On iPhone and iPad, a successfully delivered app link presents the purchase sheet. If the link cannot open it, open MorsettoAudio yourself. Opening the app does not start a purchase.

Pro labels appear inside Source, Loop and Grid → Letter menus. Free users can inspect those menus, but Pro actions remain locked. Saved custom text, spacing and loops survive Free playback and permitted edits. Saved Sidechain routes keep their source, settings and activation intent while contributing no processing or metering; their active destinations remain reserved. Choosing a Free source in a locked slot remains available, and restoring Pro resumes each route’s saved activation.

The plug-in is missing from my host

Check that your host supports AUv3 audio effects on your platform. On Mac, use the host’s documented Audio Unit rescan procedure if the installed plug-in does not appear. Reopen the host after installation if needed.

A host that only accepts other plug-in formats cannot load this AUv3 version. The current system baseline is iOS/iPadOS 18 or later and macOS 15 or later. A host/device compatibility list will be added before release; meeting the OS minimum alone does not establish host compatibility.

Audio is playing but the rhythm is missing

Check that:

  • the host transport is playing and the plug-in is not bypassed;
  • the free MORSE pattern is active, or your Pro text has been accepted with Apply Phrase;
  • Amplitude, or another audible destination, has Active Mapping enabled;
  • Depth is above zero;
  • for Morse-derived sources, the selected loop contains the chosen mark type and the audio has sound during those marks.

Dots only ignores dashes, and Dashes only ignores dots. Loop Ramp follows loop position rather than mark openings; Audio Envelope and Sidechain follow audio dynamics. These sources will not reproduce the full Morse gate.

An empty pattern, stopped transport, bypass or unavailable host timing returns the original audio, including with an audio follower selected. Very slow note values or a loop with long silent sections can make a Morse treatment difficult to notice immediately.

Disabling all mappings or setting Depth to zero returns unchanged audio after a short transition. Depth moves each destination toward its neutral behavior; for Filter Cutoff it reduces the filtered contribution while retaining the selected frequency.

There is no sound or the level is too high

First bypass the plug-in and check the source track, output routing and host meters. If the source is audible, check the loop region, active mappings, their ranges and Depth. With the normal Morse envelope driving Amplitude, a loop entirely inside a gap can keep that mapping closed.

Try one mapping at a time. Drive and increased Stereo Width can raise peaks; MorsettoAudio has no automatic makeup gain or final limiter. Leave headroom and adjust levels with your host’s track controls.

The filter can remove much of a sound’s upper range. Extreme attack/release offsets can close a short opening or remove a gap. Long fades can keep a short mark from reaching its peak or leave a gap partly open; Reshape Overlaps shortens overlapping fades into complete pulses. Zero-duration fades produce exact steps that can click. Return the Shape controls to their defaults when diagnosing an unexpected result.

Enter and apply a pattern

Custom text requires Pro. It accepts up to 20 characters after ordinary spaces are removed. Supported characters are A–Z, É/é, digits and the punctuation below:

. , : ? ' - / ( ) " = + × @

Ordinary spaces are ignored; they do not add word gaps. Other whitespace, unsupported characters and overlength input leave the accepted pattern unchanged.

Open Phrase, then choose Apply Phrase to accept edited text or Revert to return to the accepted text. Timing and mapping changes apply independently. Replacing text asks before discarding custom spacing or an explicit loop.

In either tier, one Morse unit can be 1/64, 1/32, 1/16, 1/8, 1/4, 1/2 or a whole note, with optional triplets. The default is straight 1/16.

Change spacing and loop boundaries

Spacing and loop authoring require Pro. Move the first character, or drag the leading-silence region, to shift the complete phrase while keeping its internal spacing. Move later characters independently; their dots, dashes and internal gaps stay together, and adjacent characters can touch but cannot overlap.

Choose Morse Ticks, Host Transport, Morse Ticks and Host Transport, or None. With Snap to grid enabled, new moves snap to the displayed Morse or host-beat grid; with both displayed, the nearest is used. None allows free placement while retaining the Snap preference. Changing grid or snapping never moves existing content. Before host meter observations, host snapping uses a quarter-note reference.

Move either loop boundary to select the region that repeats. Boundaries can cut through a mark or gap; extending the end beyond the phrase adds silence. Drag the labelled duration strip to move both boundaries together without changing loop length or character positions. Content outside the loop stays available for editing.

Resizing a boundary requires at least one host beat as defined by the meter’s denominator: a quarter note in 4/4, or an eighth note in 6/8. Before meter information arrives, a labelled provisional quarter-note minimum applies. Natural and restored loops can be shorter; moving a whole loop preserves its duration. Later timing or meter changes do not silently resize it.

Completed drags commit the sound change. Undo/Redo apply within the open editor; Reset spacing and loop removes leading silence and restores original spacing and natural phrase length. Replacing text or restoring state clears that editing history.

For precise edits, use Grid → Letter and the Loop menu. Beat/bar duration commands move to the next or previous duration boundary when the loop is off-grid, then apply the current snap setting. New instances use the Host Transport grid, Bars and Beats ruler and Snap to grid enabled. Ruler notation can be changed independently of timing or snapping.

On iPhone and iPad, Loop, Grid and character menus keep the snapping positions captured when opened while playback continues. Reopen a menu to use the latest grid. An authored pattern change invalidates its old editing commands. The app’s manual explains these controls and the Beats Only / Bars and Beats ruler options.

Playback starts partway through the pattern

The pattern follows the host’s current musical position, with its repeating cycle anchored to host beat zero. Starting playback in the middle of a song can therefore begin partway through the loop.

Moving the loop start selects different content; it does not delay playback. Seeking, cycling and accepted pattern edits follow the current host position. Reopening the editor does not restart the rhythm.

When stopped, a ruler update depends on the host supplying a new timing observation. If a stopped seek is not shown immediately, check again after playback resumes.

Understand the mappings

Five permanent mapping tabs can select Morse Envelope, Dots only, Dashes only, Loop Ramp, Audio Envelope or Sidechain, with their own destination, range and inversion. Sidechain requires Pro; the other sources are Free.

Select a tab to edit its mapping and view its pattern overlay. Active Mapping enables or disables that slot; selecting another tab leaves all active mappings running. Drag the range graph endpoints, or adjust them with accessibility controls. Invert reverses direction; Reset Range restores only the endpoints. Disabled mappings keep their settings. Saved Sidechain settings remain read-only while Free, although choosing another source in the slot stays available.

Each active destination can be used once. Choosing another destination resets its range to that destination’s defaults while retaining source, inversion and activation. The processing order is Drive → Filter → Width → Amplitude/Balance, regardless of tab order. Stereo Balance attenuates the opposite channel; all mappings act on the complete stereo signal.

Balance in Shape changes the relative level of dots and dashes. The Stereo Balance destination changes the left/right image. They are separate controls.

Audio Envelope and Sidechain

Audio Envelope is Free and follows the main stereo input before effects. Sidechain requires Pro and follows a separate mono or stereo input supplied by your host. Route the desired track or bus to the plug-in’s sidechain input, select Sidechain in a mapping and enable Active Mapping. The sidechain signal controls modulation without being mixed into the output.

Each source has its own Sensitivity, Floor, Attack and Release. Sensitivity changes detection without changing audible input gain; Floor sets the level mapped to zero. All mappings using the same follower share its settings; the other follower remains independent.

If the display says Waiting for Sidechain input, check whether your host exposes and has routed that input. Missing sidechain input produces zero source amount; it does not fall back to the main input. Range and inversion still apply, so a normal Amplitude mapping can be silent at zero. Available silence and unavailable input are shown separately.

The input meter shows level before follower shaping. If the response is weak, check that level, Sensitivity, Floor and the destination range. Dot Trail adds optional visual history to the live marker; one setting serves both followers and does not alter the sound. Off and Reduce Motion show a single marker.

Shape controls and the pattern display

The six controls are Balance, Attack, A. Offset, Release, R. Offset and Depth. Morse balance, fades and offsets shape Morse Envelope, Dots only and Dashes only. They do not reshape Loop Ramp or the audio followers. Controls without a role in the active mappings retain their values while editor adjustment is disabled.

For Morse Envelope, Dots only, Dashes only and Loop Ramp, the pattern curve previews the selected mapping’s source, range, inversion and Depth behavior even while inactive. Inactive previews use a dimmed dashed line. Audio followers show live observations only while active; inactive follower selections retain the shared Morse reference. The display is not the resulting audio waveform. Morse curves need host tempo, so Waiting for host tempo can appear before the host supplies it.

Save a pattern and use automation

Use your host’s project or Audio Unit preset commands to save accepted text, leading silence, spacing, loop, timing, all active and inactive mappings, both follower settings, Dot Trail, Shape controls, overlap reshaping and grid/snap/ruler preferences.

Unapplied text, drag previews, editor zoom and Undo history are temporary. Apply text you want to keep before saving. If the host restores a preset while a text draft is open, review the draft before applying it.

The host can automate the six Shape controls. Text, character positions, loops, mappings, follower settings and overlap reshaping are saved patch choices rather than additional automation parameters. Processing and automation continue with the editor closed.

If Settings could not be restored appears, the host supplied missing, invalid or unsupported saved content and the instance has kept its current settings. Unversioned development presets are unsupported. Avoid saving over the original project or preset; reopen it with a compatible build or recover a backup. Dismissing the warning does not recover the rejected settings.
